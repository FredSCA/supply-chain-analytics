
# 🤖 Módulo 3: IA Generativa (Reportes Automáticos)

Este módulo contiene la integración de Modelos de Lenguaje Grande (LLMs) para automatizar la creación de reportes ejecutivos a partir de los hallazgos de datos.

## 🎯 Objetivo de Negocio

Transformar los resultados cuantitativos del análisis exploratorio (Módulo 1) en un **Resumen Ejecutivo en lenguaje natural** de forma automática. Esto permite a los gerentes y tomadores de decisiones comprender rápidamente el estado de la operación y recibir recomendaciones accionables sin necesidad de revisar tablas o código.

## 🛠️ Stack Tecnológico

* **Lenguaje:** Python 3.x
* **IA Generativa:** Google Gemini API (Modelo Gemini 1.5 Flash)
* **Seguridad:** Python-dotenv (Manejo de variables de entorno)
* **Entorno:** Jupyter Notebook

## 📂 Archivos

* `01_generate_report.ipynb`: Notebook con la configuración de la API, diseño del *prompt* (ingeniería de prompts) y generación del texto.
