
# 🤖 Módulo 2: Machine Learning (Predicción de Volumen)

Este módulo contiene el desarrollo de un modelo predictivo para optimizar la planificación de transportes en la cadena de suministro.

## 🎯 Objetivo de Negocio

Predecir si un despacho será de **gran volumen** o **pequeño volumen** basándose en el proveedor y el día de la semana. Esto permite al área de logística dimensionar correctamente los transportes (camiones grandes vs. pequeños) y optimizar la planificación de carga, reduciendo costos operativos.

## 🛠️ Tecnologías

* Python 3.x
* Scikit-Learn (Random Forest)
* Pandas & NumPy
* Matplotlib & Seaborn
