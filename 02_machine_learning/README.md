
# 🤖 Módulo 2: Machine Learning (Predicción de Retrasos)

Este módulo contiene el desarrollo de modelos predictivos para optimizar la toma de decisiones en la cadena de suministro.

## 🎯 Objetivo de Negocio

Predecir si un despacho desde el almacén de tránsito (Dinet) llegará a la mina en el tiempo establecido o sufrirá un retraso. Esto permite anticipar desabastecimientos y optimizar los recursos logísticos.

## 🛠️ Tecnologías

* Python 3.x
* Scikit-Learn (Random Forest)
* Pandas & NumPy
* Matplotlib & Seaborn

## 📂 Archivos

* `01_delay_prediction.ipynb`: Notebook con la ingeniería de características, entrenamiento del modelo y evaluación de métricas.
